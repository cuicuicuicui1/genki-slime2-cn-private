# 文本工作流

1. 使用 `tools/nds_project.py info/list` 固定 ROM SHA 和 NitroFS 文件表。
2. 用 `data/text/messages_jp.json` 作为原文定位表，不直接改原始 ROM。
3. 在译文 JSON 中保持记录 `id`、源文和控制码；正文控制码包括 `<SPEAKER>`、`<BODY>`、`<F100>`、`<F401>`、`<F402>`、`<F400>`、`<PAGE>`、`<WAIT>`、`<END>` 等。
4. 每次提交前运行 `tools/translation_lint.py`，再对候选 ROM 做静态回读。
5. 对小窗、战车指令、HP、姓名栏等不同消费者分别记录字号、宽度、分页和关闭方式；不能因为同一条文本能编码就认为消费者安全。

普通正文回插和图形文字是两条不同的流水线：`msgdata.bin` 的记录不包含所有标题、地图和教程图形文字。
