# 构建与无头验证

## 研究脚本

`tools/patches/` 保留了实际使用过的分阶段脚本：正文、固定姓名、大名称图形、暂停图形、确认标签、原生 8/13/14px 字库和 resident row-pack。它们的头部注释会写明：输入 SHA、只改哪些 NitroFS 成员、是否改变 ARM 指令、是否有运行验证。

部分历史脚本来自本地研究布局，仍含旧的绝对路径和阶段性前置件。公开仓库已经把它们作为可读、可移植的研究参考；在运行前请把路径改成自己的工作区，并保留每个阶段的 manifest。不要直接把实验脚本当成安全发布器。

## 最小检查

```powershell
python tools/nds_project.py info --rom .\input\original.nds --expected-sha256 53a90729e750bf7288b41d205072138c14941e8810af70f4dc71a5dca6b5ba7b
python tools/translation_lint.py data	ext	ranslations_appended10.json --source data	ext\messages_jp.json
python tools/nds_project.py list --rom .\input\original.nds > build
itrofs.txt
```

## 无头模式

项目研究阶段使用过 DeSmuME 0.9.12/0.9.13 和 Python/Unicorn 的受控 ARM926 测试。仓库不捆绑模拟器；请从官方或可信来源自行安装。无头报告必须注明帧数、截图数、ROM SHA、存档来源和退出码。
