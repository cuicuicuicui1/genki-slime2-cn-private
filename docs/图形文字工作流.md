# 图形文字工作流

标题、存档、姓名输入、教程和记录画面多数不是 `msgdata.bin` 普通文本。推荐流程：

1. 先用 `tools/nds_project.py extract` 导出目标 NitroFS 文件；
2. 对自定义 `u32 count + (offset,size)` 资源包用 `archive` 子命令解包；
3. 在 `research/static-ui/` 中保存原始成员 SHA、图块预览和调色板；
4. 先证明图块布局、BG/OAM 关系和实际消费者，再替换文字；
5. 图形文字应保存原生 1 倍前后对照，并回读未改 tile、OAM、palette 和压缩边界；
6. 如未定位消费者，保持“研究候选”状态，不直接放入发行构建。

目前静态 UI 勘探重点包括 `nameentry_data.bin`、`optitle_data.bin`、`stgname_data.bin`、`toy_setumei_1.bin`、`toy_setumei_2.bin`、`pause_data.bin` 和 `select_data.bin`。仓库只公开导出结果与分析，不公开 ROM 本体。
