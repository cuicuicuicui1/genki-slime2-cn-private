# 字库与字体残缺排查

用户截图中常见的“缺一笔、红色残影、日文混入、边缘裁切”不一定是同一种问题。建议按顺序排查：

1. **确认消费者**：普通正文、mode2 小字体、mode0 8px、姓名栏和静态图形可能各走不同字库路径。
2. **确认字形是否真的写入**：检查 mapping、atlas 页、字形 stride 和 ROM→RAM 复制范围。
3. **确认原生尺寸**：不要先放大字体或扩大窗口；先按原消费者的 8/13/14px 设计。
4. **确认 palette/透明色**：红色或彩色残影可能是 4bpp palette、透明索引或旧 tile 未清空，而不是汉字本身。
5. **确认边界**：检查行宽、分页、负宽度、控制码和 tile 行尾；不要用删除最后一笔来解决溢出。
6. **冷热启动复测**：至少做一次冷启动、一次普通存档回读和一次未改场景对照。

候选字形来源和许可证见 `字体许可与源件/`、`fonts/`。新增字形需要在报告中列出字符、字号、像素设计、ID、占用槽位和消费者。
